## 2. Formulários

### 2.1 Pedido de orçamento

```txt
Campos:
- Nome
- Telefone
- Email
- Localidade
- Tipo de serviço
- Mensagem
- Fotografias

Comportamento:
- Cria Lead
- Origem: Website / Landing page
- Estado: Nova
- Prioridade: Normal
```

### 2.2 Pedido de manutenção

```txt
Campos:
- Nome
- Contacto
- Morada
- Tipo de piscina
- Volume aproximado
- Periodicidade pretendida
- Observações
- Fotografias

Comportamento:
- Cria Lead
- Tipo de serviço: Manutenção
- Estado: Nova
```

### 2.3 Pedido de assistência técnica

```txt
Campos:
- Nome
- Contacto
- Equipamento/sistema
- Descrição da avaria
- Grau de urgência
- Fotografias

Comportamento:
- Cria Lead ou Service Request
- Se urgência alta, prioridade: Alta/Urgente
- Destacar no dashboard
```
