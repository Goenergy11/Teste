# GoPools — Website Público

Este incremento corresponde ao próximo passo após a fundação técnica e a base de dados/autenticação: transformar os placeholders públicos em conteúdo institucional navegável.

## Incluído

- Homepage com posicionamento real da marca GoPools.
- Catálogo de serviços com seis áreas principais.
- Páginas individuais por serviço com descrição, benefícios, casos ideais e processo de trabalho.
- Página Sobre nós com posicionamento independente da GoPools.
- Página Contactos com área de atuação e formulário visual.
- Landing page de pedido de orçamento com formulário visual preparado para o incremento de captação.
- Componentes reutilizáveis para cards de serviço, cabeçalhos de secção e formulário visual.

## Ainda fora deste incremento

- Submissão real dos formulários.
- API routes de criação de leads.
- Upload de fotografias.
- Conteúdo SEO por localidade.
- Imagens finais, logótipo final e assets comerciais.

## Próximo incremento recomendado

O próximo PR deve ligar os formulários públicos à base de dados, criando leads automaticamente e registando o primeiro `ActivityLog` para cada submissão.
